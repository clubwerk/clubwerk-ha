# Translating Clubwerk UI texts German → English (British English)

Clubwerk is a Home Assistant add-on for sports/music clubs (originally a tennis club in Germany): drinks on a tablet instead of a paper tally sheet, receipts/deliveries, stock, billing, events, guest tabs, time tracking for staff, irrigation of courts, door access via a member app, encrypted backups, extensions/modules, multi-user admin area.

## Input / output
- Input: a JSON array of objects `{ "k": "<German source text>", "wo": ["file:line", ...] }`. `wo` shows where the text is used (context only).
- Output: ONE JSON object mapping every input `k` (exactly as given, unchanged, including leading/trailing punctuation) to its English translation. Every key must be present. Write it with a script (e.g. Python `json.dump(..., ensure_ascii=False, indent=1)`) to avoid escaping mistakes, then validate it by loading it again and checking that the key set equals the input key set and placeholders match.

## Rules
1. Placeholders `{0}`, `{1}`, `{name}` … must appear in the translation exactly as often as in the source (order may change). Never translate or drop them.
2. Many keys are fragments (a sentence split by HTML tags or variables), e.g. `", {0} ausgeblendet"` → `", {0} hidden"`, `"(steht in Home Assistant unter"` → `"(found in Home Assistant under"`. Translate the fragment so that it reads naturally when joined with its neighbours; keep leading/trailing punctuation and spacing characters (·, –, →, „…“ becomes “…”).
3. Keep it short – this is UI text on buttons, tablets and phones. Same tone as the German (friendly, plain, no jargon). German informal „du“ / formal „Sie“ both become plain “you”.
4. If a key is not natural-language text (code, a file name, CSS, a technical identifier, a brand like “Nuki”, “Hydrawise”, “Fully Kiosk Browser”), return it unchanged.
5. Keep product/brand names: Clubwerk, Home Assistant, Dropbox, Samba, WebDAV, SFTP, FTPS, Nextcloud, Hetzner Storage Box, Excel, PDF, QR code, PIN, iPhone, Safari, GitHub, Shelly, Matter, etc.
6. Keep symbols, arrows, emojis and check marks (✓ → · … ⋮). Keep numbers as they are. German UI paths like „Einstellungen → Add-ons“ in Home Assistant: translate to the English Home Assistant UI names (Settings → Add-ons, Add-on Store, Check for updates, Update, Rebuild, Log, Configuration, Info, Show in sidebar).
7. Dates/weekday/month names: translate (Mo → Mon, Montag → Monday, März → March, Uhr → (omit or “o'clock”-free form: “{0} Uhr” → “{0}”)).
8. British spelling (colour, organise, cancelled).
