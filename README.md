# Clubwerk – Home-Assistant-Add-on

Die modulare Vereinsverwaltung für Home Assistant: Getränke am Tablet statt Strichliste, Zeiterfassung, Beregnung, Türzugang und Mitglieder-App – im Erscheinungsbild des eigenen Vereins und mehrsprachig (Deutsch, Englisch, weitere Sprachen importierbar).

## Installation
1. Home Assistant → Einstellungen → Add-ons → **Add-on-Store → ⋮ → Repositories**
2. Die Adresse dieses Repositorys eintragen → **Hinzufügen**
3. „Clubwerk“ im Store auswählen → **Installieren** → **Starten**
4. In der Seitenleiste **Clubwerk** öffnen und einrichten

Neue Versionen zeigt Home Assistant automatisch an („Aktualisieren“). Die ausführliche Anleitung steht im Reiter **Dokumentation** des Add-ons.

In diesem Repository liegen keine Passwörter oder Vereinsdaten – die bleiben ausschließlich in der eigenen Home-Assistant-Installation.
