Auf den Home-Bildschirm

Code schon kopiert? Ohne den Code musst du dich in der App neu einladen lassen.

0
In Safari öffnen

Diese Seite läuft in einer anderen App. Tippe auf „…“ oder das Teilen-Symbol und dann auf „In Safari öffnen“ – oder kopiere die Adresse und öffne sie in Safari.

  1. 1
    Code kopieren
    –

    Du brauchst den Code gleich in der App. Ohne ihn musst du dich neu einladen lassen.

  2. 2
    Auf den Home-Bildschirm legen

    Tippe auf das Teilen-Symbol (oben, unten oder im Menü „…“) → „Zum Home-Bildschirm“ → „Hinzufügen“.

  3. 3
    App öffnen und Code einfügen

    Öffne Clubwerk auf dem Home-Bildschirm, füge den Code ein und gib deine PIN ein (die du eben vergeben hast).

Lege deine persönliche PIN fest (4–6 Ziffern). Damit ist dieses Handy freigeschaltet – nur für dich. Die PIN gilt auch im Verkauf am Tablet.

Einige Bereiche schalten sich erst frei, sobald du die App einmal im Vereins-WLAN öffnest.

Nicht freigeschaltet

Diese App funktioniert nur auf freigeschalteten Handys. Bitte beim Vorstand einen QR-Code holen und ihn mit diesem Handy scannen.

Fast geschafft

Gib deine PIN ein, um die Freischaltung in diese App zu übernehmen.
